## 🧩 About

**Warframe Tool** is a comprehensive overlay utility for Warframe on PC featuring a resource tracker, DPS meter, build planner, relic overlay, and customizable HUD.

Based on popular tools like **Overwolf**, **Warframe Hub**, and **AlecaFrame**.

---

## ✨ Features

### 🎮 Core Overlay
- In-game overlay menu with hotkey toggle
- Resource tracker — monitor Neurodes, Orokin Cells, Argon, and more
- DPS meter — real-time damage and status tracking
- Enemy radar — display nearby enemies and loot

### 🛠️ Build & Planning
- Build planner — theorycraft and save mod configurations
- Relic overlay — show reward probabilities and squad intel
- Market helper — price check and trade suggestions
- Codex tracker — completionist progress overview

### ⚙️ Quality of Life
- FPS counter and performance monitor
- Customizable HUD elements and themes
- Auto-screenshot on rare drops
- Config profiles per loadout
